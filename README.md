# Elsewhere · 一角色一手机

**Alpha 开发阶段。** 一个角色，一部独立手机：本地优先的 AI 虚拟生活与角色扮演应用。当前以可运行源码和可复现验证为开发基线，部分记忆、导入兼容及生成流程仍有限制，尚非稳定正式版。

本地优先的 AI 虚拟生活与角色扮演应用。当前运行入口是 `index.html → src/main.tsx → src/elsewhereApp.ts`，界面由原生 DOM 渲染。`src/App.tsx` 和 `src/index.css` 是保留的模板文件，未被当前入口引用。

## 目录

```text
src/                         正式 TypeScript、样式与 core/*.test.ts
scripts/                     单文件离线版构建脚本
public/                      经过检查的离线应用下载文件
  Elsewhere_Phase1_Standalone.html
docs/bible/                  当前产品 Bible
```

历史原型、审计证据、截图、录屏、测试日志和开发交付报告仅保留本地，不随本仓库分发。`.gitignore` 对顶层文件及公共资源采用白名单，新增文件时请先检查内容再显式放行。

根目录保留 `index.html`、`package.json`、`package-lock.json`、`tsconfig.json`、`vite.config.ts`、环境模板、元数据、README 和 CHANGELOG。`dist/` 是执行 Vite 构建后生成的发布目录。历史整理与开发环境报告保留在本地。

## 核心功能

- 每个角色拥有独立手机、身份资料、头像／头像框及主题；用户资料和角色切换保留独立入口。
- 日常聊天、多气泡、引用、编辑、撤回与重抽；面对面小说、戏中戏与独立幕间讨论。
- 日记、监控足迹及第一人称推演心声；Focus 计时、陪伴记录与历史归档。
- Identity／Relationship／Episodic／CurrentState 四层记忆上下文与现有相关性检索；完整语义检索及部分修订链仍未完成。
- API 与模型配置、私有 ST 预设导入和双模式 Prompt 管理、隔离编译预览。
- 浏览器本地存储、媒体 IndexedDB、世界备份及可生成的单文件离线版。

## 本地运行

Node.js 版本应满足 `^20.19.0 || >=22.12.0`；当前验证环境为 Node 22.19.0、npm 10.9.3。依赖版本由 `package-lock.json` 固定，已有锁文件时使用 `npm ci` 安装。

```sh
npm ci
npm run dev
```

默认入口为 `http://localhost:3000`。 **真实 AI 功能需要用户自行在终端配置兼容 API、模型和 API Key**；Key 仅在当前页面内存中使用，刷新后需重新填写。模型地址、模型名和 API Key 在应用「终端」设置；当前业务请求不读取 README 旧模板所述的 `GEMINI_API_KEY`。用户存档位于浏览器的 localStorage 与 IndexedDB，与来源地址及浏览器配置绑定；整理项目文件不会迁移这些存档。

## 检查与构建

```sh
npm run verify
```

`verify` 依次执行类型检查、全部单元测试、离线 HTML 生成和 Vite 正式构建；任何一步失败都会停止。

| 命令 | 用途 |
|---|---|
| `npm run typecheck` | 检查 src 内的应用、测试和 Vite 配置；`lint` 为同一检查的兼容入口 |
| `npm test` | 使用已锁定的 tsx 与 Node test runner 运行 `src/core/*.test.ts` |
| `npm run build` | 类型检查通过后，先生成离线 HTML，再构建 `dist/` |
| `npm run build:standalone` | 类型检查通过后，仅生成单文件离线 HTML |

单文件生成会更新 `public/Elsewhere_Phase1_Standalone.html`，此路径也是应用下载按钮使用的正式 URL。正式构建会把本次生成的离线文件放入 `dist/`。

## GitHub Pages

网页地址：[Elsewhere](https://stephanielinw.github.io/Elsewhere/)。`.github/workflows/deploy.yml` 在每次推送 `main` 时使用 Node 22、`npm ci` 和 `npm run build`，仅部署 `dist/`；也可在 Actions 手动运行。

工作流设置 `GITHUB_PAGES=true`，使 Vite 使用 `/Elsewhere/` 资源路径。本地开发及普通构建仍使用 `/`，单文件离线版继续独立生成；首页离线下载入口采用相对地址，兼容两种路径。可用 `GITHUB_PAGES=true npm run build`、`GITHUB_PAGES=true npm run preview` 在本地检查 Pages 构建。

部署不包含本机私有预设、聊天、媒体或凭据。线上网页与本地开发地址的浏览器存储相互隔离；需要迁移时请自行导出／恢复世界备份，并重新导入私有预设。API Key 仍仅在页面内存中使用；网页直连 API 仍需服务商允许该 HTTPS 来源的 CORS，不提供后端代理。

## 手机桌面：终端连接，预设 App 配置

头像框选择器与资料、桌面和聊天使用同一套头像叠加规则，保留原始 GIF 动画。点击「确认使用」会保存当前用户或已有角色的头像装扮；其他未保存的资料文字仍是草稿。新角色的装扮随「创建并进入」一并保存。不同素材分别记住微调，恢复默认只影响当前选择。

主屏幕普通 App 为「日记、监控、预设」，Dock 保持「聊天、专注、戏剧、终端」。「我的资料」、角色切换与「角色资料」仍在桌面顶部；角色资料页保留角色编辑，并承接外观、头像框素材和世界备份等手机设置；终端也提供这些原有设置的入口。定位、记忆、人物不再作为独立 App，后台记忆与正常地点记录继续保留。

1. **终端 → API 与模型**：填写兼容接口、Base URL 与仅本页有效的 Key。点击「拉取模型」才读取 `/models`，支持搜索、选择或手动填写 ID。终端按 API 与模型、外观与主题、聊天气泡 CSS、其他手机设置分区；预设管理继续独立，最大输出 Token 输入不恢复。气泡 CSS 按角色保存，支持导入 .css 到编辑器，确认应用后才保存；恢复默认只清除当前角色样式。请求按任务与已知模型选择输出上限；未知兼容服务的小说请求沿用服务端默认限制。
2. **预设 App → 选择预设**：管理 Elsewhere 原生、用户私有导入的 MoM 果实及其他兼容 ST JSON。多套预设分别保留，两个小说模式独立设置默认；未导入时显示「果实尚未导入」。
3. **当前预设 → 编辑 Prompt**：保留原始分组、搜索、启停、排序、自建条目、正文编辑与隔离编译预览。开关、排序、文风、长度和输出选项按稳定 `presetId + mode` 自动保存，150ms 合并快速修改；切换前等待写入。状态显示「保存中 / 已保存 / 保存失败」。失败保留修改，需重试或明确放弃；不会悄悄恢复默认。正文编辑器只有点击「保存条目」才提交，「取消」不改配置。

**私有 SillyTavern／MoM 预设必须由用户自行从本地导入，不随仓库或离线 HTML 分发。** 原始 JSON、内嵌第三方扩展脚本和用户模式配置不作为项目公共默认资源；请遵守原作者的署名与分发限制。

普通文本 Prompt 不再因 NSFW 等名称或正文关键词被锁定，用户可自行启停和编辑；作者默认开关与已保存的模式覆盖直接生效。snow 小剧场按产品要求继续关闭，第三方脚本／正则不执行。启用条目含尚未支持的宏时，预览明确报告兼容性诊断，不假称已完整适配。

「更新预设」先校验并展示差异，确认后才替换；按 ID 继承兼容的已保存覆盖，更新后暂停启用。未确认的正文草稿不参与更新。「导出原始文件」逐字节导出原件。**所有小说预设仍只用于隔离测试预览，没有接入真实果实小说生成**；日常聊天、日记、Focus 与幕间继续使用原生 Prompt。

复用原有私有 IndexedDB 预设库、迁移与修订冲突保护，本轮不改变存储格式。旧 FRUIT-01 原件、迁移副本和模式配置保留。新库受浏览器与来源地址隔离，未加密，也尚不包含在世界 JSON 备份中；请保留原件。旧世界存档里的原生附加预设继续按原生逻辑读取。

浏览器直连需要服务提供 CORS；离线 `file://` 来源可能为 `null`，服务拒绝时会明确报错，不引入代理。相关开发报告仅保留本地。

普通 `npm run verify` 不需要用户私有文件；额外验证真实 V6.4X 可设置本机路径，文件不会复制或打包：

```sh
ELSEWHERE_FRUIT_FIXTURE='/本机路径/原始果实V6.4X.json' npm run verify
```

## 监控、幕间与奈恩实机起点

监控心声使用角色本人第一人称、一两句短促想法；旧缓存里的分析式文字在展示时回退为人设心声，原始记录不改写。离线心声仍为规则推演，AI 润色也不作为正式心理记忆。

戏中戏点击「幕间讨论」打开右侧窗口，左侧正式剧情保留并暂停。发送只保存用户气泡；点旁边爪印才请求一次 AI 回复。未发送草稿不会进入请求，未连接 API 时不伪造幕间 AI 回复。剧本修改与回退仍在折叠工具内。

表情包不再内置默认项，只显示当前角色聊天中用户上传的图片；支持 PNG／JPG／GIF／WebP，旧默认表情历史仅保留文字占位。

奈恩新存档为空聊天、等待 API 首条消息。旧存档仅在能确认是未修改的原厂演示开场时，自动保存恢复副本并清理一次。有其他互动记录时不会自动清理，可在桌面「角色资料」底部的「奈恩 · 实机前起点」核对数量后执行一次性清理。真实记录请勿清理。恢复副本保存在当前来源的本地存储，可在同一卡片导出包含媒体的世界备份；导回会恢复清档前整个世界，而非只回滚奈恩。

实机前修正的详细验证证据与截图仅保留本地。
